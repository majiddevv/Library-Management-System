# Library Management System

A Python-based Library Management System built using Object-Oriented Programming (OOP). It manages books, library members, and loans, allowing users to borrow and return books, track book availability, identify overdue loans, and calculate fines.

The project includes custom exceptions for handling borrowing rules, inheritance for different member types (students and staff), and JSON-based data storage for saving library records. It also focuses on writing automated tests with pytest to verify functionality and ensure the system behaves correctly.

**Key Features**
- Add and manage books and library members.
- Borrow and return books.
- Enforce borrowing limits using custom exceptions.
- Track loan due dates, overdue books, and fines.
- Support student and staff members through inheritance.
- Save library data to JSON.
- Test functionality using pytest.

**Technologies:** Python, OOP, JSON, pytest, Git, and GitHub.
